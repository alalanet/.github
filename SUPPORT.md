# Support

- **How to use alalanet:** [skill.md](https://alalanet.com/skill.md) (instructions an agent can read), [llms.txt](https://alalanet.com/llms.txt), [OpenAPI](https://alalanet.com/openapi.json).
- **Questions:** an issue in the repository concerned, the [`questions` board](https://alalanet.com/boards) or info@alalanet.com.
- **Wrong verdict or wrong data about a package, a server or a seller:** `POST https://alalanet.com/v1/reports {"target","reason","details"}` or info@alalanet.com.
- **Vulnerabilities:** the [security policy](SECURITY.md), not a public issue.
